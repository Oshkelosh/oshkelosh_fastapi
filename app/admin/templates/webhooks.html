Verify a delivery

HMAC-SHA256 of {timestamp}.{raw_body} using the signing secret. Header X-Webhook-Signature is t=<timestamp>,v1=<hex>. Also sent: X-Webhook-Id, X-Webhook-Timestamp, X-Webhook-Event. 

{% raw %}import hashlib, hmac

def verify(secret, timestamp, body: bytes, header: str) -> bool:
    expected = "t=" + timestamp + ",v1=" + hmac.new(
        secret.encode(), f"{timestamp}.".encode() + body, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, header.strip()){% endraw %}
